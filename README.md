#  Console-Based Factorial Calculator

A simple console application built with Python to calculate the factorial of non-negative integers using loops, conditional statements, and string sanitization techniques.

---

## 🇬🇧 English Description

###  About The Project
This project is a CLI (Command Line Interface) application designed to practice fundamental control flow structures, mathematical operations, and robust user input handling in Python.

###  Key Features
- **Input Validation:** Restricts input to non-negative integers using `if` conditions and loop control mechanisms.
- **String Sanitization:** Employs `.lower()` and `.strip()` methods to handle user choices seamlessly regardless of uppercase letters or accidental spaces.
- **Loop Control Flow:** Utilizes `while True`, `continue`, and `break` statements to create a smooth, repeating user experience until exit.
- **Factorial Computation:** Iteratively computes factorial values using a `for` loop.

###  Built With
- **Language:** Python 3.x

## 🇹🇷 Türkçe Açıklama

###  Proje Hakkında
Bu proje, Python programlama dilinde temel kontrol yapılarını (`while`, `for`, `if-else`), döngü kontrol mekanizmalarını (`continue`, `break`) ve metin temizleme yöntemlerini pekiştirmek amacıyla geliştirilmiş konsol tabanlı bir faktöriyel hesaplama uygulamasıdır.

###  Öne Çıkan Özellikler
- **Girdi Kontrolü:** Negatif sayı girişlerini engelleyerek kullanıcının tekrar denemesini sağlar.
- **Metin Temizleme (Sanitization):** Kullanıcının devam etmek isteyip istemediğini kontrol ederken `.lower()` ve `.strip()` metodları ile büyük/küçük harf ve boşluk hatalarını önler.
- **Döngü ve Akış Kontrolü:** `while True`, `continue` ve `break` ifadeleriyle kullanıcı çıkış yapmak isteyene kadar kesintisiz bir deneyim sunar.
- **Faktöriyel Hesaplama:** `for` döngüsü kullanarak sayıların faktöriyel değerlerini adım adım hesaplar.

###  Kullanılan Teknolojiler
- **Dil:** Python 3.x
